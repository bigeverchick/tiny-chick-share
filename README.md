# tiny-chick-share
WIP local network file transfer

1. Make sure the sender and receiver devices are connected to the same network.
2. Run this code on the receiving device which you want to store the images.
3. Open the generated webpage on the sending device, select images to upload, and they will be automatically saved to the folder on the receiver.

If the original images are too large, you can choose whether to upload a compressed version.

Suitable for transferring files without installing third-party apps, which works well on a game console.
